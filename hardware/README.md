# Carrier board

Collect the organizer-confirmed chip-on-board module revision, mating connector footprint/pinout, supply rails, IO voltage, clock/reset and shared-chip project-selection requirements before layout.

Select compatible external flash/RAM and validate their protocols on FPGA. Include level translation for 5 V hosts where required. See the implementation plan for packaging references and the physical bring-up sequence. No connector or memory part has been finalized.
